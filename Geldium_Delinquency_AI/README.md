# Credit Delinquency Prediction

A machine learning classification project that explores customer credit information and predicts whether an account is delinquent.

## Dataset

The project includes customer-level credit data with features such as income, credit score, credit utilization, missed payments, loan balance, debt-to-income ratio, employment status, and recent payment history.

Target: `Delinquent_Account`.

## Workflow

- Inspect the dataset and target distribution
- Explore missing values and feature relationships
- Prepare numerical and categorical features
- Train and evaluate classification models
- Review model performance for the minority delinquency class

## Files

- `predictions.ipynb` — analysis and model experiments
- `Delinquency_prediction_dataset.csv` — project dataset
- `Geldium_Synthetic_1000.csv` — additional synthetic dataset

## Run

Open `predictions.ipynb` in Jupyter Notebook or VS Code and install the libraries imported by the notebook.
