# Machine Learning Projects

A collection of practical machine learning projects using Python. The repository covers data analysis, preprocessing, feature engineering, model training, evaluation, and selected deployment workflows.

## Projects

| Project | Type | Focus |
|---|---|---|
| [Titanic Survival Prediction](Titanic/) | Classification | EDA, feature engineering, model comparison, Flask and Streamlit apps |
| [Ames House Price Prediction](ames-house-prices/) | Regression | Missing-value handling, categorical encoding, outlier treatment, model evaluation |
| [Boston Housing Price Prediction](housing-price/) | Regression | EDA, feature transformation, regression models |
| [Geldium Delinquency Prediction](Geldium_Delinquency_AI/) | Classification | Credit-risk analysis and delinquency prediction |
| [Predictive Maintenance](predictive-maintenance-system/) | ML workflow | Predictive maintenance experiments |

## Tech Stack

Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

## Getting Started

```bash
git clone https://github.com/gopalrajane/machine-learning-projects.git
cd machine-learning-projects
```

Open the relevant project notebook in Jupyter Notebook or VS Code. For the Titanic deployment app, install the dependencies listed in [Titanic/deployment/requirements.txt](Titanic/deployment/requirements.txt).
