# Ames House Price Prediction

A regression project that predicts residential house sale prices using the Ames Housing dataset.

## Workflow

- Inspect training and test data
- Explore distributions and missing values
- Handle missing numerical and categorical values
- Encode categorical features
- Treat outliers in selected numerical features
- Train and compare regression models
- Evaluate predictions using regression metrics

## Dataset

The project uses the Kaggle House Prices dataset. The training file is not included in the repository; download `train.csv` from the competition and place it in this folder. The test dataset and sample submission are included.

Dataset description: [data_description.txt](data_description.txt).

## Files

- `train.ipynb` — preprocessing, analysis, and model experiments
- `test.csv` — test dataset
- `sample_submission.csv` — submission format
- `data_description.txt` — feature descriptions

## Run

Open `train.ipynb` in Jupyter Notebook or VS Code after placing the training dataset in this folder. Install the libraries imported by the notebook before running it.
