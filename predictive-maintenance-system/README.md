# Predictive Maintenance

A machine learning project exploring equipment failure prediction using operating and process measurements.

## Dataset

The dataset contains equipment and process features, including:

- Product type
- Air and process temperature
- Rotational speed
- Torque
- Tool wear
- Failure target and failure type

## Workflow

The notebook is used to inspect the data, explore relationships between operating conditions and failures, prepare features, and experiment with predictive models.

## Files

- `maintenance.ipynb` — analysis and model experiments
- `predictive_maintenance.csv` — dataset

## Run

Open `maintenance.ipynb` in Jupyter Notebook or VS Code and install the libraries imported by the notebook.
