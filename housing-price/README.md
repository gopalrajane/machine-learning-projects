# Boston Housing Price Prediction

A regression project that estimates median house values using housing and neighbourhood attributes from the Boston Housing dataset.

## Workflow

- Load and inspect the dataset
- Perform exploratory data analysis
- Examine feature relationships and distributions
- Select and transform features
- Train regression models
- Compare model performance using MSE and R²

## Files

- `housing_price.ipynb` — analysis and model experiments
- `housing.csv` — dataset, if provided locally
- `README.md` — project documentation

## Run

Open `housing_price.ipynb` in Jupyter Notebook or VS Code. Ensure the dataset is available at the path used in the notebook and install the required Python libraries.
